# TDD Kata

### Steps to run:

1. Clone the repository
   ```bash
   git clone https://github.com/hammyasf/tdd-kata
   ```
2. Navigate to the project directory
   ```bash
   cd tdd-kata
   ```
3. Run the following command to install the dependencies:
   ```bash
   bun install
   ```
   or simply:
   ```bash
   bun
   ```
4. Run the tests:
   ```bash
   bun test
   ```
5. Run the web server:
   ```bash
   bun run dev
   ```
